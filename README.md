# BillBlitz 💸
Welcome to BillBlitz, a sleek and modern billing system web app crafted with Flutter Web and powered by Firebase. Designed for small businesses and shops, it streamlines bill generation, management, and storage with a responsive UI. Export and print bills as PDFs effortlessly, ensuring quick and efficient digital billing solutions. 🚀

# ✨ Features

1. 🔥 Firebase Integration: Secure authentication and real-time bill storage.
2. 📄 Bill Generation: Create and manage customer bills with ease.
3. 🖨️ PDF Export & Print: Generate professional PDF bills for sharing or printing.
4. 📱 Responsive Design: Seamless experience across desktops, tablets, and mobiles.
5. 🛠️ User-Friendly Interface: Intuitive controls for fast billing workflows.


# 🛠️ Tech Stack

1. Flutter Web: Cross-platform web UI framework.
2. Firebase: Authentication and Firestore for real-time data.
3. PDF Generation: Built-in support for exporting bills as PDFs.
4. Responsive UI: Optimized for all screen sizes.
